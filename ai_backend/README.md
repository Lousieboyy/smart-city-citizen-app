# Smart City AI Backend

FastAPI backend powered by TensorFlow and OpenCV, deployed on Hugging Face Spaces.

## Repository Setup

This folder is deployed to Hugging Face Spaces. The custom `Dockerfile` handles installation of TensorFlow, OpenCV system libs, and runs Uvicorn on port `8000`.
